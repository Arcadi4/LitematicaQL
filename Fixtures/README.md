# Demo fixture

`LitematicaQL-Demo.litematic` is the `dist/schematics/all_blocks.litematic` fixture from [`schematic-renderer` 1.6.1](https://www.npmjs.com/package/schematic-renderer), renamed for the app's built-in preview. Its NBT metadata credits `EdenRose2023` as the author.

The fixture is distributed with the upstream AGPL-3.0-only package. LitematicaQL no longer depends on that package, but this vendored fixture is still covered by its license, bundled at `Renderer/third-party/schematic-renderer-LICENSE`.
